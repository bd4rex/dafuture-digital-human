## 加载和兼容策略

2026-09-08 构图校准：待机使用 `scale=792:1056,crop=720:960:32:46`，思考使用 `scale=786:1048,crop=720:960:48:38`，对话 / 主持使用 `scale=738:984,crop=720:960:2:4`。缩放均保持比例，直接在编码画面内对齐，前端不按状态改变容器或 CSS 缩放。按每段 0、0.5、1、2、3 秒抽样，三个不同动作的眼部中心中位数约为 `(361.5,199.7)`、`(360.6,196.7)`、`(360.1,196.1)`，眼距中位数约 81.5、81.9、82.3 像素（720×960 画布），相对大小差异约 1%。人物自然点头 / 侧头仍保留；这不是逐帧锁定姿态。对话 / 主持海报取片段 0.7 秒，避开开头眨眼。

手机竖屏中人物区约占可见高度 55%，预览页约 49%（矮屏预览约 43%，给测试按钮和对话留出空间）；大标题改为 14px 小提示，单行输入框约 50px 高。手机主持模式收起不可用的提问框，空间留给主持内容。较矮窗口 / 软键盘打开时仍优先保证输入与对话可见，横屏保持左右布局。

- 手机先加载待机，其他姿态在交互时加载；普通网络进入思考后预装说话，利用模型 / TTS 等待时间。桌面普通网络可在待机就绪后预装思考。
- 省流量、2G / 3G 网络仅加载当前姿态。四个 `<video>` 保留各自缓冲，切换不主动清空或重新加载已成功下载的素材；浏览器仍可能按 Range 补取数据。
- 视频使用 `muted`、`playsinline`、`webkit-playsinline` 和 `x5-playsinline="true"`，直接调用 `play()`，不把移动浏览器可能延迟的 `loadeddata` 作为播放前置条件。内联属性组合参考[西瓜播放器官方配置文档](https://h5player.bytedance.com/config/#playsinline)，不强制全屏或锁定方向。
- 自动播放被拦截时，保留同一个男性数字人的海报并显示“播放人物”；网络或解码失败时显示“重新加载”。按钮在点击事件中直接发起播放，保留用户手势上下文，不回退为旧卡通。
- 首帧等待上限为 12 秒，过期播放回调不会覆盖新姿态；页面进入后台时暂停人物视频，回到前台重试当前状态。系统启用“减少动态”时只显示真人海报。
- 视频与海报 URL 使用 `v=background-v2-aligned-20260908`。服务端对白名单文件提供正确的 MIME、HEAD、Range / 206 / 416；播放器模块使用 `no-cache`。
- 手机采用独立滚动对话区、底部输入框、16px 输入字号、44px 操作按钮及安全区留白；根据 Visual Viewport 高度调整键盘弹出时的可用空间，横屏使用左右布局。
- `/avatar?preview=1` 保留默认、思考、对话、主持四个按钮，并显示媒体状态和故障原因；普通访客页面不显示调试栏。

MP4 消除了这批资源对 Alpha 编码的依赖，但不能保证所有微信版本允许自动播放、麦克风或 TTS。上线后仍需在目标小米 15 的微信中检查首开、点击播放、四态切换、收起 / 打开键盘和切到后台再回来。桌面 Chromium 的手机视口测试不等于微信真机验收。

## 重建

在 `answer-mvp` 目录执行（需要 `ffmpeg`、`ffprobe`）：

```bash
AVATAR_BACKGROUND_DIR=/path/to/更新版视频
IDLE_FRAME_FILTER='scale=792:1056:flags=lanczos,crop=720:960:32:46' \
THINKING_FRAME_FILTER='scale=786:1048:flags=lanczos,crop=720:960:48:38' \
SPEAKING_FRAME_FILTER='scale=738:984:flags=lanczos,crop=720:960:2:4' \
PRESENTING_FRAME_FILTER='scale=738:984:flags=lanczos,crop=720:960:2:4' \
SPEAKING_POSTER_TIME=0.7 PRESENTING_POSTER_TIME=0.7 \
SPEAKING_START=1.5 SPEAKING_DURATION=3.5 \
PRESENTING_START=1.5 PRESENTING_DURATION=3.5 \
bash scripts/build-background-avatar.sh \
  "$AVATAR_BACKGROUND_DIR/对话版（最新）.mp4" \
  "$AVATAR_BACKGROUND_DIR/思考姿态（全新）.mp4" \
  "$AVATAR_BACKGROUND_DIR/默认姿势（最新版/默认姿势（最新版.mp4" \
  "$AVATAR_BACKGROUND_DIR/默认姿势（最新版/默认姿势（最新版.mp4"
```

脚本在临时目录完成转码和无音轨检查，再替换四个 MP4 与对应海报。画幅固定为 3:4；其他画幅应先确认构图，不能直接拉伸。更新素材后同步修改配置及 HTML 首屏海报的版本参数，并重启服务 / 重建部署，因为页面和配置模板在启动时读取。

## 旧透明素材

旧 `.webm` / `.mov`、`source/` 和旧构建脚本保留，供历史页面缓存和显式回退使用；当前配置不请求这些文件。不要把透明构建脚本当成本轮 MP4 构建入口，也不要仅为了清理体积删除仍可能被旧页面请求的文件。
